# 📚 Source Catalog

Master list of the references feeding this knowledge base. `status` tracks how
deeply each has been ingested:
- `metadata` — title/creator catalogued, concept covered from general references
- `transcript-needed` — creator's exact method not yet captured (paste transcript)
- `done` — transcript ingested + note written

> [!warning] Transcript limitation
> Verbatim YouTube transcripts could **not** be auto-pulled in the build
> environment (JS-rendered pages + transcript proxies returned 403). Titles +
> creators were resolved via the YouTube oEmbed API; concepts were written from
> reputable written references. For a creator's precise wording/rules, open the
> video → `...` → **Show transcript** → copy, and paste it in chat.
