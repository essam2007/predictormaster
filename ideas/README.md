# ideas

Working notes and main ideas for predictormaster — hypotheses, research
directions, and design sketches before they become code or formal docs.

- One idea per file, dated, kebab-case (e.g. `2026-05-30-carry-vs-momentum.md`).
- Promote anything confirmatory or charter-level into `docs/` (e.g.
  `docs/STRATEGY_PLAN_2026.md`, `docs/pre_registration.md`).
- Pre-register hypotheses in `docs/pre_registration.md` before running
  confirmatory tests — see the Research Integrity section of the root README.
