# True Opens

The **time anchors** of Quarterly Theory. A True Open is the start of **Q2** of a
cycle — the moment from which manipulation/Judas swings and "real" price are
measured. Price trading **above** a True Open ⇒ bullish lean; **below** ⇒ bearish
lean (a clean, mechanical bias filter).

## The standard True Opens (Daye)
| Cycle | True Open |
|---|---|
| **Yearly** | 1st Monday of **April** |
| **Monthly** | 2nd Monday of the month |
| **Weekly** | **Monday 18:00** (NY) |
| **Daily** | **00:00 / Midnight** (NY) — "True Day Open" |
| **Session (90-min)** | start of the session's Q2 |

## Why it matters here
The **Daily True Open (midnight)** is a primary [[Daily Bias]] gate, and the
session True Open frames the [[Killzones & Quarter Sequence|killzone]] you trade.
