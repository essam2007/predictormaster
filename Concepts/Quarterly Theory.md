# Quarterly Theory

The time framework everything else hangs on. Introduced by **Daye** (March 2023,
derived from ICT mentorship) and popularised/operationalised by **Bucko Trades**.

## Core idea
**Time is fractal.** Each cycle is split into **four quarters**, and within each
quarter price tends to run the **Power-of-3** sequence
(Accumulation → Manipulation → Distribution → Continuation/Reversal). The same
structure repeats across nested timeframes:

- **Year** → 4 quarters of 3 months
- **Month** → ~4 weeks
- **Week** → days (Mon–Thu as the "quarters")
- **Day** → 4 × 6-hour sessions (Asian, London, NY AM, NY PM)
- **Session** → 4 × **90-minute** quarters  ← *the intraday workhorse*
- …and micro cycles below that

A setup is "high probability" when the **same phase lines up across multiple
nested quarters** (e.g. the daily is in its manipulation quarter *and* the 90-min
quarter is too).

## Why it's the backbone here
It tells you **when** manipulation/reversals are *scheduled* to happen, so the
ICT entry tools ([[Sequential SMT (SSMT)]], [[Precision Swing Point (PSP)]],
[[Inverse FVG (IFVG) — DodgysDD Model]]) are only deployed in the right window.
